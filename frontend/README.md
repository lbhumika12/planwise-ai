# PlanWise AI — Frontend Web Application

Modern, responsive single-page React application for PlanWise AI.

## Features
- **Modern UI / UX**: Built with clean design principles, responsive sidebar, custom CSS tokens, and dark/light theme toggle.
- **Overview Dashboard**: Real-time completion metrics, progress bars, overdue alerts, and quick actions.
- **Task Management**: Real-time filtering, full text search, priority badges, category grouping, and creation/editing modals.
- **My Day Planner**: Interactive timeline visualization with chronological color-coded time blocks and schedule application.
- **AI Assistant Chat**: Natural language chat interface with suggestions, action confirmation modals, and intent breakdown.
- **Settings & Demo Data**: Timezone selection, working hours configuration, AI provider status check, and single-click demo dataset loading.

## Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Configure environment
copy .env.example .env

# 3. Start development server
npm run dev

# 4. Production build
npm run build
```
